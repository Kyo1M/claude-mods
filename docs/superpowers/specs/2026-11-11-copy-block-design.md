# copy-block 設計

## 目的

Claude Code の返答に入った貼り付け用の文面(引き継ぎ文、Slack の文面、メールの案)を、1 クリックでクリップボードに入れる。

Claude Code の標準の操作では、マウスで範囲を選ぶか、`/copy` を使う。長い引き継ぎ文は画面からはみ出すので範囲選択に手間がかかり、`/copy` は過去の返答を何番目かで指定する必要がある。この mod は対象のブロックの右上にコピーアイコンを出し、どの返答のブロックもクリック 1 回でコピーできるようにする。

## 表示と操作

```
⏺ 新しいセッションに貼る引き継ぎ文です。
                                                    ⧉
  # 引き継ぎ: レポートのレビュー
  ## 目的
  ...

  以上です。
```

1. mod：対象のブロックの 1 行目のすぐ上にある空行の右端に、アイコン `⧉` を出す。ふだんは薄く、マウスを乗せると濃くなる。
2. ヒト：アイコンをクリックする。
3. mod：ブロックの中身をクリップボードに入れ、トーストで「コピーしました(42行)」と知らせる。入らなかったときは「コピーできませんでした」と知らせる。

アイコンを 1 行目と同じ行に置かないのは、行の右端まで文字があると文字を隠すため。

コピーするのは、始まりと終わりの囲みの行(``` など)を除いた中身。行頭・行末の空白と空行は変えず、末尾に改行は足さない。

## 対象のブロック

次のすべてを満たすブロックにアイコンを出す。

- 行頭から始まる(行頭に空白や箇条書きの記号が無い)
- 閉じている
- 空白以外の中身がある
- 言語指定が無いか、`markdown`・`md`・`text`・`txt` のいずれか(大文字と小文字は区別しない)

対象にしないものと理由は次のとおり。

- `ts`・`sh` などのコードのブロック：貼り付け用の文面ではなく、コードの多い返答でアイコンが並ぶため。
- 閉じていないブロック：返答の途中で、中身が確定していないため。
- 行頭に空白や記号のあるブロック(箇条書きや引用の中など)：箇条書きを途中で区切ると、表示が崩れるため。
- 中身が空白だけのブロック：コピーするものが無いため。

「引き継ぎ」に触れた過去の返答のうち、ブロックを含む 95 件を確認した。最初のブロックの言語指定は、なしが 88 件、`markdown` が 5 件、`text` が 1 件、`yaml` が 1 件だった。

## 仕組み

返答の本文の 1 かたまり(`AssistantMessage`)の描画に割り込む。

1. 本文を上から読み、対象のブロックの前後で区切る(`splitBlocks`)。
2. 対象のブロックが無ければ、Claude Code 本体(以下、本体)の描画にそのまま渡す。
3. あれば、区切りごとに本文を差し替えて本体の描画に渡し、返ってきた描画を縦に並べる。
4. ブロックの区切りには、右上にアイコンのボタンを重ねる(`position: "absolute"`、`top: 0`、`right: 0`)。

文字の描画は本体に任せる。区切ることで変わる点は、mod が次のように補う。テストは画面の描画を扱えないので、どれも実際の画面で確かめる(完了の条件)。

- **「⏺」の印：** 返答の最初のかたまりにだけ付く印なので、最初の区切りにだけ付ける(`isFirstOfReply`)。
- **左端の位置：** 印の付く区切りは本体が 2 桁右から描くが、付かない区切りは左端から描く。印の付くかたまりでは、2 つ目以降の区切りを mod が 2 桁右へずらす。
- **アイコンの行：** 本体の描画は区切りの上に空行を 1 行持つ。アイコンはその行に重なるので、行数は増えない。
- **参照形式のリンク：** 定義(`[名前]: 行き先`)と使う箇所が別の区切りに分かれるとリンクとして描かれなくなるので、定義の行を持つ本文は区切らず、アイコンも出さない。

次の場合は割り込まず、本体の描画のままにする。

- ターミナル以外の表示(デスクトップアプリなど)
- 返答の要約の行(`isSummary`)
- fullscreen でない表示(`viewport.isFullscreen` が `false`)。クリックが届かず、アイコンを押せないため

描画の途中で失敗したとき、または返した描画が通らなかったときは、全文を本体の描画に渡し直す。返した描画が通らないと、最後に本体から受け取った描画が使われる。そのため、区切りを渡し終えた後に全文をもう一度渡しておく。

コピーは `$.ui.copy` を使う。ターミナルでは `/copy` と同じ経路でクリップボードに書く。

## 構成

```
claude-mods/
  copy-block/
    .claude-plugin/plugin.json   名前・版・説明
    hooks/hooks.json             { "modules": ["./register.tsx"] }
    hooks/register.tsx           描画への割り込みと、クリックでのコピー
    hooks/blocks.ts              本文を対象のブロックの前後で区切る処理
    hooks/blocks.test.ts         blocks.ts のテスト
    hooks/register.test.tsx      register.tsx のテスト
```

状態は持たない(`$.state` を使わない)ので、`types/index.d.ts` は置かない。

### blocks.ts(`splitBlocks`)

本文を受け取り、区切りの並びを返す。区切りは文(`{ kind: 'text', raw }`)かブロック(`{ kind: 'block', raw, body }`)で、`raw` は描画に渡す文、`body` はコピーする中身。

- **始まり：** 3 つ以上の `` ` `` か `~` が並ぶ行。行頭の空白と、箇条書き・引用の記号は付いていてもよい(対象にはしないが、ブロックとして読み飛ばす)。`` ` `` の囲みで、言語指定に `` ` `` を含む行は始まりにしない。
- **終わり：** 同じ記号が同じ数以上並ぶだけの行。
  - 行頭から始まるブロックは、行頭の空白が 3 桁までの行で閉じる。それより深い行は中身として扱う。
  - 箇条書きや引用の中のブロックは、行頭に空白のある行で閉じる。閉じる行が無ければ、始まりの行だけを文にして先を読む。
- **対象外のブロック：** 丸ごと文に含める。中に ``` があっても、ブロックの始まりとして数えない。
- **文の前後の空行：** 落とす。空行だけの文は区切りにしない。

4 つの `` ` `` で囲んだブロックは、中の ``` ごと中身にする。3 つの `` ` `` で囲んだブロックの中に、行頭の空白が 3 桁までの ``` の行があると、そこで閉じる。本体の表示も同じ読み方をするので、中に ``` の行を持つ文面は 4 つの `` ` `` で囲む。確認した過去の返答に、この形は無かった。

## テスト

`claude plugin test copy-block` で次を確かめる。

- **`blocks.test.ts`**
  - 言語指定の有無と種類による対象の判定
  - 入れ子の ```、`~~~`、閉じていないブロック、中身の無いブロック
  - 箇条書きや引用の中のブロックと、その後ろに続く対象のブロック
  - 中身の空白・空行・改行コードを変えないこと
  - 参照形式のリンクの定義を持つ本文を区切らないこと
- **`register.test.tsx`**
  - アイコンを押すと、押したブロックの中身がコピーされ、トーストが出ること
  - 区切りごとに本体へ渡し、「⏺」は最初の区切りだけに付くこと
  - 2 つ目以降の区切りを 2 桁右へずらし、アイコンを区切りの右上に重ねること
  - 対象のブロックが無い返答・要約の行・ターミナル以外・fullscreen でない表示では、本体の描画のままになること
  - コピーできなかったときに、そう知らせること

## 完了の条件

- `claude plugin validate copy-block`、`claude plugin test copy-block`、`tsc -p copy-block` が通る。
- 実際のセッション(fullscreen 表示)で、アイコンをクリックして貼り付けた内容が、ブロックの中身と一致する。
- 同じ返答を mod の有無で見比べ、差がアイコンだけである。見る返答は、前置きのあるブロック、返答の先頭のブロック、続けて並ぶブロック、右端で折り返す行、ツール実行の直後のかたまり。
- `ts` のブロックと箇条書きの中のブロックにアイコンが出ない。

## 分かっている制約

- **ctrl+o の詳細表示：** 本体の描画が区切りの上に空行を持たない。そのため区切りの間の空行が詰まり、アイコンはブロックの 1 行目の右端に重なる。クリックでのコピーはできる。描画の側から詳細表示かどうかを見分ける手段が無いので、そのままにしている。
- **HTML のコメントの中のブロック：** コメントの中にあっても、条件を満たせば対象になる。

## 入れないもの

- キーボードでコピーするコマンドとキー割り当て。マウスを使わない経路が要るようになったら足す。
